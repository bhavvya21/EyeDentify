# Model files

Google's quantized COCO EfficientDet-Lite0 TensorFlow Lite Raspberry Pi model and the COCO label map are included in this folder. Run `python scripts/download_model.py` to restore or update the model from TensorFlow's official public storage.

The model recognizes the 80 COCO object categories. It is pretrained: EyeDentify does not require a training dataset to run inference.
